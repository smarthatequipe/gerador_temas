# 🎨 Gerador de Temas

Um gerador de templates moderno e flexível que utiliza IA para criar componentes, páginas e estruturas completas de sites de forma automatizada.

## 🚀 Funcionalidades

- Geração automática de templates responsivos
- Componentes modulares e reutilizáveis
- Integração com IA para geração de código
- Estrutura semântica e acessível
- Suporte a múltiplos nichos de mercado
- CSS moderno com variáveis e flexbox/grid
- JavaScript modular e orientado a objetos
- Totalmente responsivo e mobile-first

## 🛠️ Tecnologias Utilizadas

- Node.js
- Express.js
- OpenAI GPT-4
- HTML5
- CSS3 (com variáveis CSS e flexbox/grid)
- JavaScript (ES6+)
- Sistema de templates modular

## 📦 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/smarthatequipe/gerador_temas.git
```

2. Entre no diretório:
```bash
cd gerador_temas
```

3. Instale as dependências:
```bash
npm install
```

4. Configure as variáveis de ambiente:
```bash
cp .env.example .env
```
Edite o arquivo `.env` com suas configurações

5. Inicie o servidor:
```bash
npm start
```

## 🔧 Configuração

### Variáveis de Ambiente

- `PORT`: Porta do servidor (padrão: 3000)
- `OPENAI_API_KEY`: Sua chave da API da OpenAI
- `NODE_ENV`: Ambiente de execução (development/production)

gerador_temas/

## 🎯 Uso

1. Acesse `http://localhost:3000` no navegador
2. Escolha o tipo de template que deseja gerar
3. Preencha as informações necessárias
4. O sistema irá gerar automaticamente:
   - Estrutura de arquivos
   - Componentes necessários
   - Estilos CSS
   - JavaScript interativo
   - Páginas responsivas
